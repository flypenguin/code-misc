# ghost.org

- Date of creation: 2025-05-14
- Date of last substantial update: 2025-05-14

## TL;DR (summary)

I run and know WordPress. This is simply a test compose for completeness, in case I need to test something locally.

### First impressions

- The ugly
  - Each actually useful plugin comes with a cost, and nags to you death to "finally buy it"
  - Slow and complicated
  - No usable backup function by default. Only _written content_ part of backup dump, assets of any kind are simply ignored.
- The Bad
  - Absolutely _nothing_ follows a common structure, each theme and/or plugin introduces a metric ton of options, and if it's really bad the styling is also non-default, so everything feels totally alien and taped together.
- The Good
  - Tons of themes, many of them free or a very feature-rich free version. The paid ones are usually really well maintained.
  - The Gutenberg editor is quite nice, you can really modify styling in pretty much exactly the right detail depth (e.g. sliders and absolute values for changing the padding on list items, without digging into HTML source)
